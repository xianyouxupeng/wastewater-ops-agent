# 城镇污水处理厂污染物排放标准要点摘录（样例文档）

> 本文档为脱敏样例，内容参照 GB 18918-2002《城镇污水处理厂污染物排放标准》一级 A 标准等公开标准的通用要点整理，仅供知识库功能演示。实际执行限值以环评批复与本厂排污许可证为准。

## 1. 一级 A 标准主要指标限值（日均值）

| 指标 | 限值 |
|---|---|
| COD | 50 mg/L |
| BOD5 | 10 mg/L |
| SS | 10 mg/L |
| 氨氮 | 5(8) mg/L（括号内为水温 ≤12℃ 时的限值） |
| 总氮 | 15 mg/L |
| 总磷 | 0.5 mg/L |
| pH | 6~9 |
| 粪大肠菌群 | 1000 个/L |

## 2. 与运行控制相关的要点

- 氨氮限值在水温 ≤12℃ 时放宽至 8 mg/L，但硝化系统在低温下本身能力下降，不可依赖该放宽项，应提前提高 SRT。
- 总氮达标依赖反硝化：需保证足够碳源（进水 BOD/TN 比宜大于 4，不足时需外加碳源如乙酸钠）、足够缺氧段停留时间与较低的内回流携带 DO。
- 总磷 0.5 mg/L 通常需要生物除磷 + 化学除磷协同实现；化学除磷药剂投加点与投加量需结合出水磷浓度与 pH 调整。
- SS 10 mg/L 对二沉池与深度处理（过滤）要求高，出现漂泥、翻泥时 SS 极易超标。
- 取样与评价：排放口自动监测数据按日均值评价，手工监测按标准规定频次执行；在线仪表须按规范定期校准比对。

## 3. 污泥控制标准

- 污泥含水率：脱水污泥一般要求低于 80%；深度脱水可低于 60%。
- 污泥稳定化：好氧消化或厌氧消化达标后方可视情况农用等处置；泥饼外运须执行转移联单制度。

## 4. 超标处置的通用流程

1. 发现在线数据接近或超过限值：立即手工取样复测，排除仪表失准。
2. 复测确认超标：按厂内应急预案上报，启动工艺调整（参考故障排查清单），必要时启用应急处理措施。
3. 留存样品、记录处置过程，配合监管部门要求。
4. 超标原因查明前不得盲目大幅调整工艺参数，避免次生波动。
