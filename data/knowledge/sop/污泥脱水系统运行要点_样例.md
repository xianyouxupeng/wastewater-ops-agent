# 污泥脱水系统运行要点（样例文档）

> 本文档为脱敏样例，内容为带式/板框/离心脱水机的通用运行控制要点，供知识库功能演示使用。实际执行以本厂正式规程与设备说明书为准。

## 1. 脱水前调质

- 药剂：常用聚丙烯酰胺（PAM），阴离子型为主；投加浓度一般 0.1%~0.2%（溶液），投加量按干泥计约 2~5 kg PAM/tDS，最佳投加量通过泥饼含水率与滤液澄清度判断。
- PAM 溶解：配制后需熟化 30~60 分钟方可投加；搅拌速度不宜过高（避免剪切断链失效）；溶液存放超过 24~48 小时药效下降。
- 投加过量表现：滤液黏稠、泥饼过黏、滤布易堵塞；投加不足表现：滤液浑浊带泥、泥饼薄且含水率高。

## 2. 泥饼含水率控制

- 带式脱水机泥饼含水率一般 78%~82%；离心机 78%~85%；板框机（高压）可低于 65%。
- 含水率超标常见原因鉴别：
  - 滤液浑浊 → 药剂投加不足或药效失效（查 PAM 配制浓度与熟化时间）；
  - 滤液清但泥饼厚薄不均 → 进泥量波动或布泥不均；
  - 滤布板结/堵塞 → 冲洗水压不足或滤布老化，安排冲洗或更换滤布；
  - 进泥浓度过低（<2%）→ 浓缩环节出问题，先查浓缩池/浓缩机。

## 3. 运行巡检要点

- 滤带/滤布冲洗水压：带式机一般不低于 0.5 MPa，冲洗不良是跑泥第一原因。
- 进泥流量与浓度稳定：波动大会导致泥饼质量不稳定。
- 滤液 SS 与澄清度：每班观察，浑浊立即调整药耗。
- 离心机：关注主轴承温度与振动；差速调整影响泥饼干度与回收率。

## 4. 药耗异常

- 吨泥药耗明显升高时按顺序排查：
  1. PAM 溶液浓度是否正确（计量泵行程、配制记录）；
  2. 进泥浓度是否下降（浓缩效果差 → 单位干泥对应的药剂有效接触不足）；
  3. 污泥性质变化（消化污泥、长期储存污泥较难脱水，需增加药耗或换药剂型号）；
  4. 设备因素（滤布堵塞、螺旋磨损）。

## 5. 安全与环保

- 脱水机房注意通风（硫化氢、沼气积聚风险），动火作业先检测。
- 滤布更换与清理作业须停机断电挂牌。
- 泥饼暂存与外运执行台账与转移联单制度。
